# Mechanic App MVP

Tell it a car and a repair task; it returns a strict-JSON job sheet —
`{ tools: [], parts: [], steps: [] }` — generated by Claude (`claude-opus-4-8`).

```
mechanic-app/
├── backend/    Express API · POST /api/repair · @anthropic-ai/sdk
└── frontend/   Expo app (web + iOS + Android) · Car + Task UI
```

## 1. Backend

```bash
cd backend
npm install
# add your key:  echo "ANTHROPIC_API_KEY=sk-ant-..." >> .env   (or edit .env)
npm start            # http://localhost:3001
```

The API key is read from `backend/.env`. Get one at https://console.anthropic.com/.

**Endpoints**

- `GET  /api/health` → `{ ok, keyConfigured }`
- `POST /api/repair` → body `{ "car": "2015 Honda Civic", "task": "Replace front brake pads" }`
  → `{ "tools": [...], "parts": [...], "steps": [...] }`

The strict shape is enforced server-side via Claude **structured outputs**
(`output_config.format` + JSON schema), so the response is always valid JSON in
that exact shape — not just prompt-coaxed.

## 2. Frontend

```bash
cd frontend
npm install
npm run web          # browser  → http://localhost:8081
# or: npm start      # then press i / a for iOS / Android
```

The app posts to `http://localhost:3001`. On a physical device/emulator, change
`API_BASE` in `frontend/App.js` to your machine's LAN IP.

## Quick test (no frontend)

```bash
curl -s localhost:3001/api/repair \
  -H 'content-type: application/json' \
  -d '{"car":"2015 Honda Civic","task":"Replace front brake pads"}' | jq
```
